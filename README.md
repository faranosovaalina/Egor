# PSE для круглой струи (MATLAB)

Реализация линейных параболизованных уравнений устойчивости (PSE) для
круглой (турбулентной) струи по заданному среднему течению, в постановке
K. Gudmundsson, *Instability wave models of turbulent jets from round and
serrated nozzles*, PhD thesis, Caltech, 2009 (см. также Gudmundsson &
Colonius, JFM 689, 2011). Для набора чисел Струхаля и одной азимутальной
моды `m` код считает комплексное поле давления `p'(x, r)` волнового пакета
Кельвина–Гельмгольца.

Файлы:

| файл | назначение |
|---|---|
| `pse_jet.m` | решатель (одна функция, вспомогательные функции внутри) |
| `example_jet.m` | пример на модельной струе M = 0.9, построение графиков |

Код работает в MATLAB и GNU Octave (≥ 6), тулбоксы не нужны.

## Использование

```matlab
mf.x   = x;      % [Nx x 1]  x/D_j
mf.r   = r;      % [Nr x 1]  r/D_j, желательно начиная с r = 0
mf.U   = U;      % [Nx x Nr] U/U_j
mf.V   = V;      % [Nx x Nr] V/U_j          (необязательно)
mf.T   = T;      % [Nx x Nr] T/T_j          } одно из двух; при p = const
mf.rho = rho;    % [Nx x Nr] rho/rho_j      } rho*T = 1

opts.M  = 0.9;   % U_j/c_j
opts.x0 = 0.2;  opts.x1 = 15;  opts.dx = 0.1;

res = pse_jet(mf, [0.3 0.5 0.7], 0, opts);    % St, m

% давление: p'(x,r,theta,t) = Re{ res(k).p * exp(i*m*theta - i*omega*t) }
pcolor(res(1).x, res(1).r, real(res(1).p)); shading interp
```

Если среднее поле задано в других масштабах (например, `rho/rho_inf`,
`T/T_inf`), перед вызовом пересчитайте его на параметры струи на срезе
сопла: `U/U_j`, `rho/rho_j`, `T/T_j`, координаты в `D_j`.

Выходные поля `res(k)`: `x`, `r`, `alpha(x)`, `phase = ∫α dx`, функция
формы давления `phat`, полное давление `p = phat·exp(i∫α dx)`, признак
сходимости итераций `converged`, собственное значение `alphaLST` в `x0`.
Все параметры описаны в `help pse_jet`.

Решение линейное: амплитуда задаётся нормировкой `max_r |p̂(x0, r)| = opts.amp`.
Для сравнения с экспериментом/LES амплитуду каждого (St, m) нужно
калибровать отдельно, как у Gudmundsson & Colonius.

## Постановка

Переменные `q = [ρ, u_x, u_r, u_θ, T]`, обезразмеривание по `D_j, U_j,
ρ_j, T_j`, давление по `ρ_j U_j²`, уравнение состояния
`p = ρT/(γM²)`. Линеаризованные уравнения Эйлера относительно среднего
течения `(U, V, ρ̄, T̄)(x, r)`:

* неразрывность, три уравнения импульса (неконсервативная форма) и
  уравнение энергии в форме `DT/Dt + (γ−1) T ∇·u = 0`;
* учитываются `V` и все производные среднего течения по `x` и `r`
  (непараллельные члены);
* давление восстанавливается как `p' = (ρ̄ T' + T̄ ρ')/(γM²)`.

Анзац PSE: `q' = q̂(x,r) exp(i(∫α dx + mθ − ωt))`, `ω = 2π St`.
Подстановка даёт

```
(−iωA + iαC + imD + E) q̂ + B ∂q̂/∂r + C ∂q̂/∂x = 0,
```

`∂²/∂x²` в невязких уравнениях отсутствует. Условие нормировки
`∫ q̂ᴴ ∂q̂/∂x r dr = 0` даёт итерации на каждом шаге:
`α ← α − i ∫q̂ᴴ ∂q̂/∂x r dr / ∫|q̂|² r dr`.

Численный метод:

* **r** — коллокация Чебышёва (Гаусс–Лобатто) с отображением на `[0, rmax]`;
  по умолчанию `sinh`-сгущение точек около слоя смешения `r = 0.5`
  (`opts.rc`, `opts.beta`), доступно также отображение Малика;
* **x** — неявная схема Эйлера первого порядка (как у Gudmundsson);
* **начальное условие** — мода К-Г локальной (параллельной) задачи
  устойчивости в `x0`, обобщённая задача на собственные значения по α.
  Ложные моды Чебышёва отсеиваются сравнением спектров на двух сетках
  (`Nr` и `0.8·Nr`), выбирается наиболее неустойчивая мода в диапазоне
  фазовых скоростей `opts.cphRange`. Можно задать `opts.alphaGuess`;
* **граничные условия**: на оси — условия регулярности
  (`m=0`: `u_r=u_θ=0`, `∂(ρ,u_x,T)/∂r=0`; `|m|=1`: `ρ=u_x=T=0`,
  `∂u_r/∂r=0`, `u_r + i m u_θ=0`; `|m|≥2`: все нули); на `rmax` — однородные
  условия Дирихле;
* **ограничение на шаг**: маршевание PSE устойчиво при
  `Δx > 1/|Re α|` (Li & Malik 1996). По умолчанию `dx` автоматически
  увеличивается до `1.1/Re α(x0)`. Альтернатива — `opts.dropDpdx = true`
  (отбросить `∂p̂/∂x` в уравнении осевого импульса), это снимает
  ограничение и позволяет брать малый шаг.

Среднее течение интерполируется (`pchip`) с исходной сетки, производные
считаются на исходной сетке разностями 2-го порядка. За пределами
исходной сетки по `r` поле «замораживается», а его производные равны нулю.

## Проверка

* Локальная задача (параллельный tanh-профиль): при θ → 0 собственное
  значение сходится к дисперсионному соотношению вихревого слоя
  (Michalke) для `m = 0, 1, 2`, холодной и горячей струи, M = 0.5…0.9;
  например, `M = 0.5, St = 0.3, m = 0`: экстраполяция по θ = 0.01, 0.005
  даёт `α = 1.586 − 1.090i`, вихревой слой — `1.591 − 1.090i`.
* PSE на параллельном течении сохраняет `α(x) = α_LST` и `|q̂| = const`
  с точностью ~1e-14.
* Сходимость по `Nr` и `dx` — см. раздел ниже / запустите `example_jet.m`
  с разными `opts.Nr`, `opts.dx`.

## Замечания и ограничения

* Уравнения невязкие, как у Gudmundsson; турбулентная вязкость не
  учитывается.
* PSE описывает одну (К-Г) волну; ниже по течению за точкой нейтральности
  решение затухает, акустическое поле в дальней зоне на `rmax` не
  излучается (условия Дирихле). Для дальнего поля обычно используют
  проекцию давления на цилиндрической поверхности `r ≈ 1…2 D`
  (Kirchhoff/FW-H), как в диссертации.
* Начальное сечение `x0` должно быть там, где слой смешения разрешён
  сеткой (`Nr` порядка 100–150 при θ ≈ 0.02). Если автоматический выбор
  моды не срабатывает (предупреждение), увеличьте `Nr`/`beta` или задайте
  `opts.alphaGuess`.
* Время: одна частота при `Nr = 100` и ~100 шагах — несколько секунд в
  MATLAB.
