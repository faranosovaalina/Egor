# PSE для круглой струи (MATLAB)

Реализация линейных параболизованных уравнений устойчивости (PSE) для
круглой (турбулентной) струи по заданному среднему течению, в постановке
K. Gudmundsson, *Instability wave models of turbulent jets from round and
serrated nozzles*, PhD thesis, Caltech, 2009 (см. также Gudmundsson &
Colonius, JFM 689, 2011). Для набора чисел Струхаля и одной азимутальной
моды `m` код считает комплексное поле давления `p'(x, r)` волнового пакета
Кельвина–Гельмгольца.

Файлы:

| файл | назначение |
|---|---|
| `pse_jet.m` | решатель (одна функция, вспомогательные функции внутри) |
| `example_jet.m` | пример на модельной струе M = 0.9, построение графиков |

Код работает в MATLAB и GNU Octave (≥ 6), тулбоксы не нужны.

## Использование

```matlab
mf.x   = x;      % [Nx x 1]  x/D_j
mf.r   = r;      % [Nr x 1]  r/D_j, желательно начиная с r = 0
mf.U   = U;      % [Nx x Nr] U/U_j
mf.V   = V;      % [Nx x Nr] V/U_j          (необязательно)
mf.T   = T;      % [Nx x Nr] T/T_j          } одно из двух; при p = const
mf.rho = rho;    % [Nx x Nr] rho/rho_j      } rho*T = 1

opts.M  = 0.9;   % U_j/c_j
opts.x0 = 0.2;  opts.x1 = 15;  opts.dx = 0.1;

res = pse_jet(mf, [0.3 0.5 0.7], 0, opts);    % St, m

% давление: p'(x,r,theta,t) = Re{ res(k).p * exp(i*m*theta - i*omega*t) }
pcolor(res(1).x, res(1).r, real(res(1).p)); shading interp
```

Если среднее поле задано в других масштабах (например, `rho/rho_inf`,
`T/T_inf`), перед вызовом пересчитайте его на параметры струи на срезе
сопла: `U/U_j`, `rho/rho_j`, `T/T_j`, координаты в `D_j`.

Выходные поля `res(k)`: `x`, `r`, `alpha(x)`, `phase = ∫α dx`, функция
формы давления `phat`, полное давление `p = phat·exp(i∫α dx)`, признак
сходимости итераций `converged`, собственное значение `alphaLST` в `x0`.
Все параметры описаны в `help pse_jet`.

Решение линейное: амплитуда задаётся нормировкой `max_r |p̂(x0, r)| = opts.amp`.
Для сравнения с экспериментом/LES амплитуду каждого (St, m) нужно
калибровать отдельно, как у Gudmundsson & Colonius.

## Постановка

Переменные `q = [ρ, u_x, u_r, u_θ, T]`, обезразмеривание по `D_j, U_j,
ρ_j, T_j`, давление по `ρ_j U_j²`, уравнение состояния
`p = ρT/(γM²)`. Линеаризованные уравнения Эйлера относительно среднего
течения `(U, V, ρ̄, T̄)(x, r)`:

* неразрывность, три уравнения импульса (неконсервативная форма) и
  уравнение энергии в форме `DT/Dt + (γ−1) T ∇·u = 0`;
* учитываются `V` и все производные среднего течения по `x` и `r`
  (непараллельные члены);
* давление восстанавливается как `p' = (ρ̄ T' + T̄ ρ')/(γM²)`.

Анзац PSE: `q' = q̂(x,r) exp(i(∫α dx + mθ − ωt))`, `ω = 2π St`.
Подстановка даёт

```
(−iωA + iαC + imD + E) q̂ + B ∂q̂/∂r + C ∂q̂/∂x = 0,
```

`∂²/∂x²` в невязких уравнениях отсутствует. Условие нормировки
`∫ q̂ᴴ ∂q̂/∂x r dr = 0` даёт итерации на каждом шаге:
`α ← α − i ∫q̂ᴴ ∂q̂/∂x r dr / ∫|q̂|² r dr`.

Численный метод:

* **r** — коллокация Чебышёва (Гаусс–Лобатто) с отображением на `[0, rmax]`;
  по умолчанию `sinh`-сгущение точек около слоя смешения `r = 0.5`
  (`opts.rc`, `opts.beta`), доступно также отображение Малика;
* **x** — неявная схема Эйлера первого порядка (как у Gudmundsson);
* **начальное условие** — мода К-Г локальной (параллельной) задачи
  устойчивости в `x0`, обобщённая задача на собственные значения по α.
  Ложные моды Чебышёва отсеиваются сравнением спектров на двух сетках
  (`Nr` и `0.8·Nr`), выбирается наиболее неустойчивая мода в диапазоне
  фазовых скоростей `opts.cphRange`. Можно задать `opts.alphaGuess`;
* **граничные условия**: на оси — условия регулярности
  (`m=0`: `u_r=u_θ=0`, `∂(ρ,u_x,T)/∂r=0`; `|m|=1`: `ρ=u_x=T=0`,
  `∂u_r/∂r=0`, `u_r + i m u_θ=0`; `|m|≥2`: все нули); на `rmax` — однородные
  условия Дирихле;
* **ограничение на шаг**: маршевание PSE устойчиво при
  `Δx > 1/|Re α|` (Li & Malik 1996). По умолчанию `dx` автоматически
  увеличивается до `1.1/Re α(x0)`. Альтернатива — `opts.dropDpdx = true`
  (отбросить `∂p̂/∂x` в уравнении осевого импульса), это снимает
  ограничение и позволяет брать малый шаг.

Среднее течение интерполируется (`pchip`) с исходной сетки, производные
считаются на исходной сетке разностями 2-го порядка. За пределами
исходной сетки по `r` поле «замораживается», а его производные равны нулю.

## Проверка

* Локальная задача (параллельный tanh-профиль): при θ → 0 собственное
  значение сходится к дисперсионному соотношению вихревого слоя
  (Michalke) для `m = 0, 1, 2`, холодной и горячей струи, M = 0.5…0.9;
  например, `M = 0.5, St = 0.3, m = 0`: экстраполяция по θ = 0.01, 0.005
  даёт `α = 1.586 − 1.090i`, вихревой слой — `1.591 − 1.090i`.
* PSE на параллельном течении сохраняет `α(x) = α_LST` и `|q̂| = const`
  с точностью ~1e-14.
* Сходимость на модельной струе из `example_jet.m` (m = 0, x0 = 0.2):

  | вариант | St = 0.3: max\|p\| при x | \|p\|(x=6) | St = 0.7: max\|p\| при x | \|p\|(x=6) |
  |---|---|---|---|---|
  | Nr=100, dx авто (0.49 / 0.14) | 17.7 при 3.14 | 6.58 | 3.76 при 1.29 | 0.86 |
  | Nr=140, dx авто | 17.7 при 3.14 | 6.58 | 3.83 при 1.27 | 0.28 |
  | Nr=100, dropDpdx, dx=0.1 | 18.7 при 3.30 | 7.94 | 3.89 при 1.20 | 0.96 |
  | Nr=100, dropDpdx, dx=0.05 | 18.7 при 3.30 | 8.10 | 3.92 при 1.15 | 1.06 |

  Рост волны и положение максимума от сетки почти не зависят; по dx
  сходимость первого порядка (неявный Эйлер). Далеко за максимумом, где
  волна уже затухла в 5–10 раз, решение для высоких St чувствительно к
  `Nr`: при St = 0.7 и Nr = 100 мода К-Г в x0 разрешена недостаточно
  (код выдаёт предупреждение). Поэтому для St ≳ 0.5 берите `Nr ≥ 140`
  или начинайте маршевание чуть ниже по потоку.

## Замечания и ограничения

* Уравнения невязкие, как у Gudmundsson; турбулентная вязкость не
  учитывается.
* PSE описывает одну (К-Г) волну; ниже по течению за точкой нейтральности
  решение затухает, акустическое поле в дальней зоне на `rmax` не
  излучается (условия Дирихле). Для дальнего поля обычно используют
  проекцию давления на цилиндрической поверхности `r ≈ 1…2 D`
  (Kirchhoff/FW-H), как в диссертации.
* Начальное сечение `x0` должно быть там, где слой смешения разрешён
  сеткой (`Nr` порядка 100–150 при θ ≈ 0.02). Если автоматический выбор
  моды не срабатывает (предупреждение), увеличьте `Nr`/`beta` или задайте
  `opts.alphaGuess`.
* Итерации по α на каждом шаге — метод секущих по невязке условия
  нормировки (простая итерация `α ← α − i·F` при малом `dx` расходится).
* Время: основная стоимость — решение систем 5Nr×5Nr на каждой итерации;
  одна частота при `Nr = 100` и ~100 шагах — порядка минуты.

# Звуковое поле по формуле Кирхгофа

| файл | назначение |
|---|---|
| `kirchhoff_pse.m` | интеграл Кирхгофа по конической (осесимметричной) поверхности для всех St из mat-файла PSE |
| `kirchhoff_arc.m` | точки наблюдения на полярной дуге |
| `pse_pressure_at.m` | прямое давление PSE в точках (для сравнения в ближнем поле) |
| `pse_interp_xr.m` | интерполяция поля с PSE-сетки (сплайн по x, Лагранж по r) |
| `make_pse_mat.m` | PSE для модельной струи + mat-файл в формате `example_new_mean_jet_to_mat.m` |
| `run_kirchhoff.m` | пример: mat-файл → давление на дуге 200R |
| `test_kirchhoff_jet.m` | тесты: St = 0.5, m = 0, M = 0.4…2, дуга 200R и ближнее поле |

Всё совместимо с MATLAB R2014a+ и Octave (только `bsxfun`, без неявного
расширения массивов, без локальных функций в скриптах).

```matlab
gen = [0.5 1.0; 14 4.0];                 % образующая: (x0,r0) -> (x1,r1)
obs = kirchhoff_arc(100, 10:2:170, 0);   % дуга 200R, R = 0.5
K   = kirchhoff_pse('pse_M0p90_Tinf1p00_m0_St_sweep.mat', gen, obs);
% K.p [Nobs x nSt], K.absp, K.realp, K.imagp, K.phase (рад)
```

Формула (временной множитель `exp(-iωt)`, неподвижная среда вне S,
`k = ω/c∞`, `c∞ = sqrt(T∞/T_j)/M`):

```
p(x) = ∫_S [ p ∂G/∂n − G ∂p/∂n ] dS,   G = exp(ik|x−y|)/(4π|x−y|),
```

нормаль — наружу от струи. На S `p = p_m(x,r)·exp(imφ')`; интеграл по
азимуту — правило трапеций (точность до машинной для периодической
функции, число точек выбирается автоматически по `k` и расстоянию до
поверхности), по образующей — трапеции. Узлы образующей — PSE-сетка по
x данного St (каждый интервал делится на `opts.nSub = 4`; при `nSub = 1`
ровно PSE-сетка). Интерполируется медленная огибающая
`p·exp(−i∫α dx)` и отдельно фаза `∫α dx` (`alpha_all` из mat-файла),
`∂p/∂x = (∂H/∂x + iαH)·exp(i∫α dx)`. Результат — в плоскости φ = 0;
для другого φ умножить на `exp(imφ)`.

## Проверки

* Точные решения уравнения Гельмгольца (мультиполи
  `h_l(kρ) P_l^m(cos θ) e^{imφ}`, m = 0, 1, 2) на замкнутой поверхности
  «торец–конус–торец»: относительная ошибка 1–3·10⁻⁴.
* Сходимость: `nSub = 4 → 8` меняет результат на 0.4–2.6 %; `nSub = 1`
  (ровно PSE-сетка, ~6 точек на длину волны при dx ≈ 1/Re α) даёт ошибку
  10–100 % — поэтому по умолчанию `nSub = 4`.
* `test_kirchhoff_jet.m`, St = 0.5, m = 0, модель струи из
  `example_new_mean_jet_to_mat.m` (x0 = 0.5, Nr = 160), конус
  (0.5, 1) → (14, 4), дуга 200R:

  | M | максимум диаграммы | Кирхгоф vs прямой PSE, r = 5, x ∈ [6, 13] |
  |---|---|---|
  | 0.4 | 15° | не сравнимо (поле PSE при r ≳ 2 — шум) |
  | 0.9 | 95° (артефакт) | не сравнимо |
  | 1.3 | 30° | 49 % |
  | 1.5 | 30° | 8 % |
  | 2.0 | 45° | 27 % (Кирхгоф на 12–17 % выше) |

## Ограничения (важно)

* **Сверхзвуковые струи** (волны Маха, `c_ph·M/c∞ > 1`): максимум
  диаграммы устойчив к выбору поверхности (M = 2: разброс 4–5 %,
  M = 1.5: 8–20 %), в ближнем поле Кирхгоф согласуется с PSE. При M = 2
  разница 27 % систематическая и уменьшается при удалении поверхности от
  струи — по-видимому, это численное затухание волн в самой PSE (схема
  первого порядка, dx ≈ 0.2), а не ошибка интеграла.
* **Дозвуковые струи**: излучаемая часть волнового пакета мала
  (доли процента от гидродинамического давления), поэтому результат
  чувствителен ко всем ошибкам — точности PSE, усечению открытой
  поверхности (давление на её концах не мало), положению конуса.
  На модели разброс уровня при разных конусах — до 2 раз, а боковые
  углы фактически шум. Поле PSE при r ≳ 2 D для M ≤ 0.9 уравнению
  Гельмгольца не удовлетворяет (невязка ~100 %, и уменьшение dx до 0.05
  не помогает), поэтому:
  - конус проводите близко к струе, в области, где PSE-поле
    достоверно (r ≈ 1 у среза, расширяясь вместе со слоем смешения);
  - проверяйте устойчивость результата к положению конуса и к
    `opts.taper` (окно у концов), прежде чем ему доверять.
* В `example_new_mean_jet_to_mat.m` вызываются функции
  `interp_meanfield_U_local` и `Uj_x_at`, которых нет в репозитории, а
  файл сохраняется с `-v7.3` (HDF5) — для чтения в Octave сохраняйте с
  `-v7`. Модель среднего течения при `x0 = 0.1` даёт слой смешения
  тоньше 0.015 D, и мода К-Г при Nr = 200 не подтверждается
  (предупреждение `pse_jet`), поэтому в тестах взято `x0 = 0.5`.

## Что делает код

Среднее течение в каждом сечении «замораживается» (V = 0, d/dx = 0), решается
тот же набор линеаризованных уравнений Эйлера, что и в `pse_jet`, как
обобщённая задача на собственные значения по α: `(−iωA + imD + E + B ∂r) q = α(−iC) q`.

**Критический слой.** Уравнения сингулярны при `U(r_c) = ω/α`. Пока мода
неустойчива (Im α < 0), `Im(ω/α) > 0`, а в слое смешения `U' < 0`, поэтому
`Im r_c < 0`: точка лежит под вещественной осью, контур интегрирования
проходит над ней. При Im α → 0 она подходит к оси и уходит в верхнюю
полуплоскость; если контур остаётся вещественным, то он «перескакивает»
особенность, и решение перестаёт быть продолжением предыдущих. Поэтому
контур деформируется: `r(s) = s + i·h(s)`, `h = amp·B(s)`, где `B` — гладкая
(C∞) «шапка» с плато вокруг `Re r_c` и компактным носителем (на оси и
внешней границе контур вещественный точно). Амплитуда выбирается так, чтобы
контур оставался над `r_c` не менее чем на `d = margin·δ` (δ — толщина слоя
смешения), и включается гладко (softplus), так что вдали от нейтрального
сечения контур вещественный. Сторона обхода σ фиксируется в первом
(неустойчивом) сечении. Производные берутся на комплексной сетке, то есть
`d/dr = (1/r'(η)) d/dη`.

**Аналитическое продолжение профиля.** U(r), T(r) заданы таблицей на
вещественных r. Для комплексных r они продолжаются AAA-аппроксимацией
(полюса считаются, `opts.profileFun` позволяет подставить свои аналитические
профили). Ширина горба автоматически уменьшается, пока контур не перестанет
пересекать полюса профиля; если не получилось, сечение помечается в
`polesCrossed_all`, и выдаётся предупреждение.

**Сопровождение моды.** Первое сечение — собственное значение, ближайшее к α
из PSE; далее метод Ньютона для пары (α, q) с начальным приближением из
предыдущего сечения (экстраполяция по x), запасной вариант — полный спектр.

## Результаты теста (`test_lst_jet.m`, M = 0.9, St = 0.5, m = 0)

* Нейтральное сечение LST: x ≈ 2.86; в PSE Im α меняет знак при x ≈ 3.4
  (разница — непараллельные эффекты, учтённые в PSE).
* **Без деформации** контура мода за нейтральным сечением переходит в
  непрерывный спектр: α становится вещественным (Im α ~ 1e-30…1e-170),
  α = ω/U(r) для некоторого вещественного r — типичный симптом проблемы
  критического слоя.
* **С деформацией**: Im α > 0 гладко продолжается (x = 3.25…4.75);
  изменение ширины горба в 2 и 3 раза меняет α менее чем на 0.9 % и 1.7 %,
  увеличение Nr с 140 до 200 — на 3 %; без деформации разница с базовым
  вариантом ≈ 1.7 (в единицах α, порядка 40 %).
* Далее (x ≳ 5 в этом примере) α подходит к `ω/U_max` — точке ветвления
  непрерывного спектра ядра струи (`dbranch_all < 0.03`). Мода сливается с
  непрерывным спектром, результат начинает зависеть от контура и физического
  смысла не имеет; код выводит сообщение, с какого x это происходит.

## Ограничения

* **Профиль должен быть аналитическим.** Исходная модель в
  `example_new_mean_jet_to_mat.m` имеет излом на границе потенциального ядра
  (`R = rc`); AAA ставит там полюса на расстоянии ~0.006 от вещественной оси,
  и контур, отклонённый больше, пересекает их — продолжение в этой области
  недостоверно (код это детектирует: `polesCrossed_all`). На такой модели
  заметно только в сечениях, где критический слой оказывается рядом с изломом
  (в тесте 2 сечения из 15). Для чистого результата сгладьте излом
  (`meanflow_model(..., smoothEps)`) или используйте гладкие данные (RANS и т.п.).
* При очень тонком слое (начало струи, δ ≲ 0.03) нужно достаточное
  разрешение (`Nr`, `opts.beta`): полюс критического слоя находится на
  расстоянии d от контура, шаг сетки должен быть заметно меньше d.
* Точные значения α на старте отличаются от PSE на ~0.3 % (интерполяция
  профиля и сетка), что видно и без деформации.
* Диапазон допустимых значений `margin`: при 0.6δ и больше горб становится
  слишком высоким и результат теряется уже до слияния с непрерывным спектром.
  По умолчанию 0.3.

## Заметки по ходу работы

1. Первый вариант горба (гауссиан × окно, обнуляющее его на концах) при
   критическом слое около оси (`r_c ≈ 0.3`) раздувал амплитуду в 5 раз, и
   контур уходил на `h ≈ 1.5`; гауссов профиль в комплексной плоскости растёт
   как `exp(h²/δ²)`, и результат зависел от параметров. Заменён на «шапку» с
   плато и компактным носителем, высота которой равна ровно нужной.
2. Сначала казалось, что 1 % расхождения со стартовым α PSE — ошибка
   метода; это не так: деформация зацепила полюса излома (AAA), без
   деформации результат сходится по `Nr` к значению, отличающемуся от PSE на
   0.3 %.
3. С деформацией и без неё результаты совпадают в неустойчивой области
   (|Δα| ≤ 5.6·10⁻³ при x ≤ 2, ~0.1 % — горб включается плавно немного
   раньше нейтрального сечения), так что деформация не портит решение там,
   где она не нужна.
4. Простая проверка «найдено ли аналитическое продолжение»: результат не
   должен зависеть от формы контура. Это выполняется до x ≈ 4.75; дальше α
   подходит к ω/U_max, и зависимость появляется — это физический предел
   существования дискретной моды, а не ошибка кода.
